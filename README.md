# conPanna

Prototype framework and tactics for constrained-pattern unification and narrowing.

## Build

Install Lean through [elan](https://github.com/leanprover/elan), then run:

```bash
lake build
```

`Expresso/Expresso.lean` contains the semantic framework and its initial examples. `conPanna/conPanna.lean` contains the remaining theory, unification, narrowing, and example code.
