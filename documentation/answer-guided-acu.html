Working draft · 14 October 2026

Answer-Guided Certification of Complete Sets of ACU Unifiers

Authors to be added. Draft prepared from the conPanna project notes.

Abstract

Rewriting tools such as Maude compute finite complete sets of unifiers modulo associativity, commutativity and unit (ACU). A proof assistant that uses such a set must trust that it is complete: that every solution is an instance of some returned answer. We give a small calculus whose derivations prove completeness of a given answer set in Lean. The calculus never recomputes unifiers. Its single ACU rule takes its arithmetic data (minimal particular solutions and a Hilbert basis) from the answers themselves, and checks it with closed Presburger side conditions. Each leaf of a derivation is one unifier, closed by naming the answer that covers it. We prove the rules sound once, as generic theorems over a quotient representation of bags, and sketch why a derivation always exists when the answer set is complete. A Lean prototype certifies linear, nonlinear and mixed free/ACU problems against Maude's verbatim output.

1Introduction

Unification modulo ACU, the theory of a commutative monoid, appears whenever system states are modelled as multisets: process bags, message soups, object configurations. Maude computes finite complete sets of ACU unifiers, and symbolic analyses such as narrowing and symbolic reachability rely on them. If such an analysis is to be checked in a proof assistant, the completeness of each unifier set becomes a proof obligation.

Completeness is a ∀∃ statement. For every solution $\gamma$ of the problem, there is an answer $\sigma$ and a witness $\beta$ with $\gamma = \beta\circ\sigma$. Two obvious routes are unattractive. Verifying an ACU unification algorithm inside the assistant means formalizing Diophantine solving and the combination of theories. Replaying the algorithm as a proof search duplicates exactly the work the external tool has already done.

We take a third route. The external tool already holds the answers, and the answers contain the hard data. A minimal complete set of ACU unifiers is built from the minimal solutions of a linear Diophantine system, and those solutions are visible in the answers as multiplicities of their variables. Our calculus reads them back, lets the proof assistant check a few closed arithmetic facts about them, and uses a generic theorem to turn those facts into a case split of the solution space. What remains at each leaf is a single unifier, and the given answer set covers it by assumption.

Contributions.

  1. A judgment $\langle\alpha;E;D\rangle \Vdash \Sigma$ and a calculus for free constructors plus ACU bags (§3). It has one ACU rule, Solve, whose data comes from the answers.
  2. Soundness: each rule is one generic theorem, so every derivation proves completeness (§4).
  3. Search completeness (§5), stated for any rule set meeting four local obligations: if the answer set is complete, a derivation exists. Leaves are unifiers, so the standard syntactic notion of completeness supplies every leaf's witness.
  4. A shallow Lean encoding in which bag sorts are quotient types isomorphic to multisets, side conditions are discharged by omega, and leaves by ac_rfl. It is evaluated against Maude's output (§7).

2Preliminaries

2.1Sorts, bags and stratification

A signature has free sorts, given by ordinary constructors with no equations, and bag sorts $\mathsf{Bag}(S)$ for an element sort $S$. A bag term is built from $\varnothing$, singletons $\{t\}$ with $t : S$, and the binary union $\cup$. Union is associative and commutative with unit $\varnothing$. We write $k\cdot T$ for the union of $k$ copies of $T$.

In a singleton $\{t\}$ the term $t$ is an alien: it is not built from $\cup$, so the bag theory treats it as an opaque atom. The term follows the literature on combining unification algorithms. In $X \cup \{\mathsf{wait}(N)\}$ the alien is $\mathsf{wait}(N)$.

Definition 1 (stratified). A signature is stratified if no sort reaches itself through $\mathsf{Bag}$. Equivalently, the sorts can be ranked so that every alien has a strictly lower rank than its bag.

Process bags over a free state type are stratified. A tree whose node holds a bag of trees is not; we exclude it (§9).

2.2Solutions, unifiers and completeness

A problem $E_0$ is a finite set of equations $s \stackrel{?}{=} t$ over original variables $X_1,\dots,X_n$. We distinguish two notions:

  • A solution is a valuation $\gamma$ of the original variables in the intended model (bags as finite multisets, free sorts as their inductive types) such that $\gamma(s)=\gamma(t)$ for every equation. It is semantic.
  • A unifier is a substitution $\theta$ by terms, which may contain variables, such that $\theta(s) =_{ACU} \theta(t)$ as terms. It is syntactic.

An answer $\sigma$ covers $\gamma$ if $\gamma = \beta\circ\sigma$ for some valuation $\beta$ of $\sigma$'s own variables, the witness. The answer's variables are thus existentially quantified. The same wording applies to unifiers, with $\beta$ a substitution.

Definition 2 (completeness). A finite answer set $\Sigma$ is complete for $E_0$ if every solution is covered by some $\sigma\in\Sigma$. It is syntactically complete if every unifier is covered, up to $=_{ACU}$, by some $\sigma\in\Sigma$.

Semantic completeness is the statement we prove in Lean. Syntactic completeness is what a unification algorithm guarantees, and it is the hypothesis of our search-completeness argument. Answer soundness, that each $\sigma$ is a unifier, is a separate and easy check, made answer by answer.

Notation. In examples, original variables are written $X?$, the answers' own (existential) variables $U!$, and the fresh variables introduced by a derivation $Z$.

2.3Counting, particular solutions and Hilbert bases

Fix bag variables $V_1,\dots,V_n$ of one bag sort and an element $e$. The count vector of $e$ is $v\in\mathbb N^n$, where $v_i$ is the number of copies of $e$ in $V_i$.

Example 1 (count vectors). Let $X=\{a,a,b\}$ and $Y=\{b\}$. The count vector of $a$ is $(2,0)$, that of $b$ is $(1,1)$, and every other element has $(0,0)$. A pair of bags is the same thing as one count vector per element, with only finitely many nonzero.

Bag equations become linear equations over count vectors: union adds counts, $k\cdot X$ multiplies them by $k$, and $\{t\}$ contributes $1$ at the value of $t$ and $0$ elsewhere. Suppose the aliens of the system are pairwise distinct. Then at each element the system reads

$$A\,v = d_c \ \text{ if } e = a_c, \qquad A\,v = 0 \ \text{ otherwise.}$$

Here $A\in\mathbb Z^{r\times n}$ collects the variable coefficients (left side minus right side) and $d_c$ is the net count of alien $a_c$ (right side minus left side).

Example 2 (from bags to arithmetic). The equation $X \cup X \stackrel{?}{=} Y \cup \{a\}$ has $A = (2,\ {-1})$. At the element $a$ the count vector $(x,y)$ must satisfy $2x = y + 1$; at every other element it must satisfy $2x = y$. For instance $X=\{a,b\}$, $Y=\{a,b,b\}$ is a solution: at $a$, $(1,1)$ gives $2=1+1$; at $b$, $(1,2)$ gives $2=2$.

Write $\le$ for the component-wise order on $\mathbb N^n$.

Definition 3. A particular solution of $A v = d$ is any of its solutions. It is minimal if no other solution lies strictly below it. The Hilbert basis of $A v = 0$ is the set of its minimal nonzero solutions; it is finite.
Example 3 (one particular solution, one basis vector). For $2x = y+1$ the solutions are $(1,1), (2,3), (3,5), \dots$; the only minimal one is $p=(1,1)$. For $2x = y$ the solutions are $(0,0), (1,2), (2,4),\dots$, and the Hilbert basis is $\{(1,2)\}$. Every solution at $a$ is $(1,1) + k\,(1,2)$, and every solution elsewhere is $k\,(1,2)$. Read back as bags, with a bag $U!$ collecting the $k$'s: $$X \mapsto \{a\}\cup U!,\qquad Y\mapsto \{a\}\cup U!\cup U! .$$ This is Maude's most general answer. The multiplicities of $U!$ in the two bindings are the basis vector $(1,2)$, and the multiplicities of $a$ are the particular solution $(1,1)$.
Example 4 (several basis vectors). For $X\cup Y \stackrel{?}{=} Z \cup Z$ each element gives $x + y = 2z$. The Hilbert basis has three vectors, $(2,0,1)$, $(1,1,1)$ and $(0,2,1)$, one answer variable each: $$X\mapsto U_1!\cup U_1!\cup U_2!,\qquad Y\mapsto U_2!\cup U_3!\cup U_3!,\qquad Z\mapsto U_1!\cup U_2!\cup U_3! .$$ Decompositions need not be unique: $(2,2,2) = (2,0,1)+(0,2,1) = 2\cdot(1,1,1)$. Our rule never needs uniqueness.

Every solution of $Av = 0$ is a sum of Hilbert basis vectors with multiplicities in $\mathbb N$. Every solution of $A v = d$ lies above some minimal particular solution. Our rule uses only the following weaker domination properties, which are closed formulas of Presburger arithmetic:

$$\textsf{(S2)}\ \ \forall v.\ Av=d_c \Rightarrow \bigvee_{p\in P_c} p\le v \qquad\qquad \textsf{(S3)}\ \ \forall v.\ Av=0 \wedge v\neq 0 \Rightarrow \bigvee_{b\in B} b\le v$$
Example 5 (domination drives a decomposition). Take $x+y=2z$ and the solution $v=(3,1,2)$. By (S3) some basis vector lies below it, here $(2,0,1)$. Subtracting it leaves $(1,1,1)$, again a solution, since both vectors solve a homogeneous system. Next $(1,1,1)$ lies below itself, and subtracting it leaves $0$. So $v = (2,0,1)+(1,1,1)$. Peeling one basis vector at a time is exactly how the soundness proof of §4 builds the fresh bags.
Example 6 (what the checks reject). Drop $(1,1,1)$ from the basis of Example 4. Then (S3) fails at $v=(1,1,1)$, because neither $(2,0,1)$ nor $(0,2,1)$ lies below it, and omega refuses the formula. Conversely, for $X\cup X\stackrel{?}{=}Y\cup Y\cup\{a\}$ the system at $a$ is $2x = 2y+1$. It has no solution, so $P=\varnothing$ is accepted: (S2) reduces to the parity fact that $2x\neq 2y+1$.

3The Calculus

3.1Judgment

A state is a triple $\langle\alpha;E;D\rangle$ over a context of variables:

  • $\alpha$ maps each original variable to a term;
  • $E$ is a set of pending equations;
  • $D$ is a set of disequations between aliens.
Definition 4 (validity). $\langle\alpha;E;D\rangle\Vdash\Sigma$ holds if for every valuation $\rho$ of the context variables with $\rho\models E$ and $\rho\models D$, the solution $\rho\circ\alpha$ is covered by $\Sigma$.

The initial state is $\langle\mathrm{id};E_0;\varnothing\rangle$, and its validity is exactly completeness of $\Sigma$. The context variables are universally quantified: initially the original variables $X?$, later also the fresh variables $Z$ introduced by Solve. The answers' own variables $U!$ never enter a state; they are instantiated only by Cover's witness.

3.2Free rules and identification

Rules are read bottom-up. A rule without premises closes its branch.

$$\frac{\langle\alpha;E;D\rangle\Vdash\Sigma}{\langle\alpha;E,\ t\stackrel{?}{=}t;D\rangle\Vdash\Sigma}\ \textsf{Delete} \qquad \frac{\langle\alpha;E,\ \vec s\stackrel{?}{=}\vec t;D\rangle\Vdash\Sigma}{\langle\alpha;E,\ f(\vec s)\stackrel{?}{=}f(\vec t);D\rangle\Vdash\Sigma}\ \textsf{Decomp}$$
$$\frac{}{\langle\alpha;E,\ f(\vec s)\stackrel{?}{=}g(\vec t);D\rangle\Vdash\Sigma}\ \textsf{Clash}\ (f\ne g) \qquad \frac{}{\langle\alpha;E,\ V\stackrel{?}{=}t;D\rangle\Vdash\Sigma}\ \textsf{Occurs}\ (V \sqsubset t)$$
$$\frac{\langle\alpha[V{:=}t];\ E[V{:=}t];\ D[V{:=}t]\rangle\Vdash\Sigma}{\langle\alpha;E,\ V\stackrel{?}{=}t;D\rangle\Vdash\Sigma}\ \textsf{Elim}\ (V\notin t)$$
$$\frac{\langle\alpha;E,\ s\stackrel{?}{=}t;D\rangle\Vdash\Sigma \qquad \langle\alpha;E;D,\ s\neq t\rangle\Vdash\Sigma}{\langle\alpha;E;D\rangle\Vdash\Sigma}\ \textsf{Identify} \qquad \frac{}{\langle\alpha;E;D,\ s\neq t\rangle\Vdash\Sigma}\ \textsf{Distinct}\ (s=_{ACU}t)$$

In Decomp and Clash, $f$ and $g$ are free constructors. In Occurs, $V\sqsubset t$ means that $V$ occurs strictly inside $t$ along free constructors. By stratification, an occurrence of $V$ can never pass through a bag of its own sort. Identify applies to two aliens. Its equal branch continues at their strictly lower sort.

3.3The ACU rule

Let $\mathcal B$ be some pending equations of one bag sort (possibly a single one), and $E'$ the rest. Let $V_1,\dots,V_n$ be the bag variables of $\mathcal B$.

Alien classes and compatibility. Two aliens of $\mathcal B$ are in the same class if they are syntactically identical or connected by pending equations in $E'$; such equations stay in $E'$ and are solved later, at the aliens' lower sort. Pick a representative $a_c$ for each class $c$. Two classes are incompatible if they can never denote the same element: a pair of their aliens is recorded as distinct in $D$, or the equation between them is refuted by the free rules (Clash, Occurs). Otherwise they are compatible. A clique is a set of pairwise compatible classes. Under a given valuation, the classes that denote the same element always form a clique. Let $A$ and $d_c$ be as in §2.3.

The rule's data is a finite set $P_c\subseteq\mathbb N^n$ for each class, and $B=\{b_1,\dots,b_k\}\subseteq\mathbb N^n\setminus\{0\}$. For a choice $\pi=(p_c)_c\in\prod_c P_c$, define the substitution

$$\theta_\pi \;=\; \Bigl[\,V_i := \bigcup_c p_{c,i}\cdot\{a_c\} \;\cup\; \bigcup_{j=1}^{k} b_{j,i}\cdot Z_j\,\Bigr]_{i=1..n}$$

with $Z_1,\dots,Z_k$ fresh bag variables, one per basis vector.

$$\frac{\textsf{(S1)}\quad \textsf{(S2)}\quad \textsf{(S3)} \qquad \langle\alpha\theta_\pi;\ E'\theta_\pi;\ D\theta_\pi\rangle\Vdash\Sigma\ \ \text{for every }\pi\in\textstyle\prod_c P_c}{\langle\alpha;\ E',\mathcal B;\ D\rangle\Vdash\Sigma}\ \textsf{Solve}$$

Side condition (S1) says $A p = d_c$ for $p\in P_c$, and $A b = 0$ for $b\in B$. (S3) is the domination property of §2.3. (S2) is required for every clique $G$, since the classes of $G$ may denote one element whose count is the sum of theirs:

$$\textsf{(S2)}\ \ \forall v.\ A v=\textstyle\sum_{c\in G} d_c \;\Rightarrow\; \exists\,(p_c\in P_c)_{c\in G}.\ \ \sum_{c\in G}p_c\le v .$$

For a single class this is the domination property of §2.3. All side conditions are closed formulas of linear arithmetic, so they are checked, not searched. Identify is needed only when (S2) fails for some clique; it then decides a pair of that clique.

Example 7 (when Identify is needed). In $\{w(K)\}\cup P \stackrel{?}{=} \{w(K)\}\cup\{\mathit{idle}\}\cup\{w(M)\}\cup Q$, the aliens $w(K)$ and $\mathit{idle}$ are incompatible, while $w(K)$ and $w(M)$ are compatible. The classes give $p = q$, $p = q + 1$ and $p = q + 1$, with $P = \{(0,0)\}, \{(1,0)\}, \{(1,0)\}$ and $B = \{(1,1)\}$. For the clique $\{w(K), w(M)\}$, merging gives $p = q+1$, and every solution lies above $(0,0)+(1,0)$, so (S2) holds. One Solve covers both $K = M$ and $K \neq M$. In contrast, for $X\cup X\stackrel{?}{=}\{a\}\cup\{b\}$ each class alone gives $2x = 1$, so $P_a = P_b = \varnothing$, but merging gives $2x = 2$ with the solution $x = 1$, which lies above no sum. (S2) fails for $\{a, b\}$, and Identify must split $a = b$ from $a \neq b$.

The data is read off answers of native unification. For a class $c$, take the count equation at its element: the equation keeping only the aliens of $c$, replaced by a constant. In its answers, the multiplicity of that constant in the binding of $V_i$ gives $p_{c,i}$; (S2) for a clique is checked the same way, with the clique's aliens merged into one constant. The basis is read the same way from the answers of the homogeneous equation, with the aliens removed: the multiplicity of an answer variable $U_j!$ in the binding of $V_i$ is $b_{j,i}$, and each such variable becomes one fresh variable $Z_j$ of the derivation. The homogeneous equation always has answers, so $B$ is available even when the equation itself has none; then $P_c=\varnothing$ for some class, Solve has no premises, and the derivation proves that there is no solution.

3.4Leaves

$$\frac{}{\langle\alpha;\varnothing;D\rangle\Vdash\Sigma}\ \textsf{Cover}\quad(\sigma\in\Sigma,\ \ \alpha =_{ACU} \beta\circ\sigma)$$

The witness $\beta$ maps the answer's variables $U!$ to terms over the context. It is supplied by the external tool, found by ACU matching of $\alpha$ against $\sigma$; the proof assistant only checks the equation.

3.5Derived rules

The familiar bag rules are instances of Solve:

  • $X\cup Y \stackrel{?}{=} \varnothing$ has no aliens and $B=\varnothing$.
  • $X\cup Y\stackrel{?}{=}\{a\}$ has $P=\{(1,0),(0,1)\}$, $B=\varnothing$.
  • $X\cup Y \stackrel{?}{=} Z\cup W$ has no aliens, and $B$ is the four "grid cell" vectors, which correspond to the refinement property of free commutative monoids.

4Soundness

Theorem 1 (rule validity).Mechanized If all premises of a rule are valid, so is its conclusion. Hence a derivation of $\langle\mathrm{id};E_0;\varnothing\rangle\Vdash\Sigma$ proves that $\Sigma$ is complete for $E_0$.
Proof. The free rules and Identify follow from injectivity and disjointness of constructors, a size argument for Occurs, and case analysis on equality. Cover is the definition of covering. For Solve, let $\rho$ satisfy $\mathcal B$ and $D$, and let $v_e$ be the count vector of each element $e$ under $\rho$. Bags are multisets. The classes whose aliens denote $e$ form a clique $G_e$, possibly empty, so $A v_e = \sum_{c\in G_e} d_c$.
  • At each element $e$ with $G_e$ nonempty, (S2) for $G_e$ gives $p_c\in P_c$ $(c\in G_e)$ with $\sum_{c} p_c\le v_e$, and by (S1) the difference solves the homogeneous system. Removing these copies leaves a homogeneous solution at every element; the chosen $p_c$ form one choice $\pi$, since every class denotes exactly one element.
  • Now induct on the total size of the remaining bags. If some count vector $v_e$ is nonzero, (S3) gives $b_j\le v_e$, and by (S1) the vector $v_e-b_j$ is still a solution. Remove one copy of $e$ according to $b_j$, apply the induction hypothesis, and add $\{e\}$ to $Z_j$.
The result is a valuation of the $Z_j$ under which $\rho = \rho'\circ\theta_\pi$, with $\pi$ the chosen particular parts. The premise for $\pi$ then applies. ∎

5Search Completeness

We state search completeness for any rule set whose rules meet four local obligations. A change to one rule then only requires re-checking that rule.

Fix a rank for every sort: a total order in which a sort's terms only contain terms of the same or lower rank. Stratification makes every bag sort rank strictly above its element sort. Each rule application acts at one rank. For a rule with conclusion $\langle\alpha;E;D\rangle$ and a premise $\langle\alpha';E';D'\rangle$:

  • (O1) Validity. The rule is sound (Theorem 1).
  • (O2) Unifier preservation. There is a substitution $\tau$ with $\alpha'=\alpha\circ\tau$, such that $\tau\circ\mu$ unifies $E$ whenever $\mu$ unifies $E'$.
  • (O3) Applicability. In every state with $E\neq\varnothing$ reached by the strategy, some rule applies with data meeting its side conditions.
  • (O4) Progress. Each non-closing step strictly decreases a well-founded measure, and has finitely many premises.

(O2) gives an invariant: for every unifier $\mu$ of $E$, $\alpha\circ\mu$ is a unifier of $E_0$. It holds initially ($\alpha=\mathrm{id}$, $E=E_0$) and is preserved by every step. The disequations $D$ play no part in it.

Theorem 2 (search completeness).Relative to O1–O4 Let the rules and strategy satisfy (O1)–(O4), and let $\Sigma$ be syntactically complete for $E_0$. Then $\langle\mathrm{id};E_0;\varnothing\rangle\Vdash\Sigma$ has a finite derivation.
Proof. Build the tree with the strategy. It is finite by (O4) and König's lemma. By (O3), every leaf either closes by a rule without premises or has $E=\varnothing$. In the latter case, the invariant with $\mu=\mathrm{id}$ makes $\alpha$ a unifier of $E_0$. Syntactic completeness then gives $\sigma\in\Sigma$ and $\beta$ with $\alpha=_{ACU}\beta\circ\sigma$, and Cover closes the leaf. ∎

Leaves are single unifiers with variables, not sets of values. So we never face the question whether one answer covers a whole region of solutions; syntactic completeness, which the unification algorithm guarantees, answers it directly. The derivation proves the semantic statement, and the two notions of completeness meet exactly at Cover.

Discharging the obligations. The strategy processes ranks from the top down. At a free rank it uses the free rules. At a bag rank it applies Solve, unless (S2) fails for a clique of compatible classes; then it applies Identify to a pair of that clique.

A proof that the answers' most general elements always expose the full Hilbert basis, which is observed in §7 but not needed for Theorem 2.

6Examples

6.1Mixed free and ACU

Take $X? \cup \{w(N?)\} \stackrel{?}{=} Y?\cup\{w(M?)\}$ with $w$ a free constructor over $\mathbb N$. Maude returns four answers, numbered from 0; answer 1 is $X?\mapsto U_3!\cup\{w(U_2!)\}$, $Y?\mapsto U_3!\cup\{w(U_1!)\}$, $N?\mapsto U_1!$, $M?\mapsto U_2!$, and answer 3 is $X?, Y?\mapsto U_1!$, $N?, M?\mapsto U_2!$. The derivation has two leaves:

IDENTIFY  w(N?) vs w(M?)
├─ equal:    DECOMP  N? = M?;  ELIM M? := N?
│            SOLVE   aliens cancel: x = y;   P = {0},  B = {(1,1)}
│            leaf    X? ↦ Z1,  Y? ↦ Z1,  M? ↦ N?
│            COVER   answer 3,  U1! := Z1,  U2! := N?
└─ distinct: SOLVE   at w(N?): x + 1 = y,  P = {(0,1)}
                     at w(M?): x = y + 1,  P = {(1,0)}
                     elsewhere: x = y,     B = {(1,1)}
             leaf    X? ↦ Z1 ∪ {w(M?)},  Y? ↦ Z1 ∪ {w(N?)}
             COVER   answer 1,  U1! := N?,  U2! := M?,  U3! := Z1

6.2Nonlinear

For $X?\cup Y?\stackrel{?}{=}Z?\cup Z?$, each element contributes $x+y=2z$. Its Hilbert basis $\{(2,0,1),(1,1,1),(0,2,1)\}$ is exactly the multiplicities of the variables of Maude's most general answer:

$$X?\mapsto U_1!\cup U_1!\cup U_2!,\qquad Y?\mapsto U_2!\cup U_3!\cup U_3!,\qquad Z?\mapsto U_1!\cup U_2!\cup U_3!.$$

One Solve step, with fresh variables $Z_1, Z_2, Z_3$ for the three basis vectors, produces this answer as its only leaf, covered with $U_j! := Z_j$. Condition (S3) is the single formula

$$x+y=2z\ \wedge\ (x,y,z)\ne 0 \;\Rightarrow\; (2\le x\wedge 1\le z)\vee(1\le x\wedge1\le y\wedge 1\le z)\vee(2\le y\wedge1\le z),$$

which omega proves. Dropping $(1,1,1)$ from $B$ makes it fail at $v=(1,1,1)$, so an incomplete basis is rejected.

7Implementation and Evaluation

Shallow encoding. Each bag sort is an instance of one template: raw trees $\varnothing \mid \{s\} \mid t\cup u$, the least congruence generated by the ACU axioms, and the quotient type. We prove once that the quotient is isomorphic to Multiset. Every ACU fact then reduces to element counts. Free sorts are ordinary Lean inductives, so Decomp and Clash are built-in constructor facts. Associativity, commutativity and unit instances for union let ac_rfl check Cover and answer soundness.

Mechanized. The isomorphism; every rule of §3 as a generic theorem, including Solve in its clique form; and completeness of Maude's verbatim answer sets for a linear, a nonlinear (§6.2) and a mixed (§6.1) problem.

9Limitations and Future Work

  • Recursive bag sorts. Supporting them needs a joint quotient over mutually defined raw syntax. The rules are unchanged; only the normal-form theorem changes.
  • Cost of the side conditions. omega is exponential in the worst case, and its behaviour on large systems is unmeasured.
  • Producer. A Maude strategy that emits derivations (§5) and a compact derivation format are future work.
  • Other theories and interpreted functions. Operators with further equations (idempotence, etc.) and interpreted functions such as $n+m$ on $\mathbb N$ are out of scope. A successor $n+1$ is allowed, because it is the constructor $\mathsf{succ}\,n$.
  • Nested bags. Whether ac_rfl handles two union operators at once, as in $\mathsf{Bag}(\mathsf{Bag}(S))$, is untested.

AGlossary

ACU
Associativity, commutativity and unit: the equations of a commutative monoid. Here the monoid is bags under union.
Alien
A term $t$ in a singleton $\{t\}$. It is opaque to the bag theory.
Stratified
No sort contains bags of itself, directly or indirectly.
Solution
Values for the original variables that satisfy the equations.
Unifier
A substitution by terms with variables that satisfies the equations as ACU identities.
Covers
$\sigma$ covers $\gamma$ if $\gamma=\beta\circ\sigma$ for some witness $\beta$.
Complete
Every solution (semantic) or every unifier (syntactic) is covered by some answer.
Count vector
The multiplicities of one element across the bag variables.
Particular solution
A solution of $Av=d$ with $d\ne0$; minimal if nothing else lies below it.
Hilbert basis
The minimal nonzero solutions of $Av=0$; every solution is an $\mathbb N$-combination of them.
Domination
Every solution lies above some given vector, conditions (S2) and (S3).
Witness
The instantiation $\beta$ that shows an answer covers a solution or a unifier.
Variables $X?$, $U!$, $Z$
Original variables of the problem; the answers' own, existentially quantified variables; fresh variables introduced by a derivation.
Search completeness
A derivation exists whenever the answer set is complete. It is needed for automation, not for trust.
