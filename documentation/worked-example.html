Nested Boxes: One Certificate from Root to Leaves

The paper presents the calculus one rule at a time. This page follows a single complete certificate, so you can see how the rules work together: which rule fires where, what each state looks like, and why the finished tree proves that the answer set is complete.

1The problem

There are two kinds of bags here, one inside the other. Elements $a, b, \dots$ form bags of sort Bag. A free constructor $\mathsf{box}$ turns a bag into a box, and boxes form bags of sort Boxes. Both bag sorts are ACU: union $\cup$ is associative and commutative, with unit $\varnothing$. The variables are $X, Y, W, Z$ of sort Bag and $R$ of sort Boxes.

The problem has three boxes, which we name once and use throughout:

$$A = \mathsf{box}(\{a\}\cup X),\qquad B = \mathsf{box}(Y\cup W),\qquad C = \mathsf{box}(Z),$$ $$\{A\}\cup R \;\stackrel{?}{=}\; \{B\}\cup\{C\}.$$

A solution is a value for every variable that makes the two sides equal bags of boxes. One example:

$$\gamma:\quad X=\varnothing,\ \ Y=\{a\},\ \ W=\varnothing,\ \ Z=\{b\},\ \ R=\{\mathsf{box}(\{b\})\}.$$

Both sides become $\{\mathsf{box}(\{a\}),\ \mathsf{box}(\{b\})\}$. We follow this $\gamma$ through the whole tree in §5.

Maude returns 16 unifiers $\sigma_0,\dots,\sigma_{15}$. The certificate uses only three of them; every other one is an instance of these (for example $\sigma_8$ is $\sigma_{11}$ with $U_2 = U_3 = \varnothing$), so it is never needed.

Answer$X$$Y$$W$$Z$$R$
$\sigma_7$$U_1$$U_2$$U_3$$\{a\}\cup U_1$$\{\mathsf{box}(U_2\cup U_3)\}$
$\sigma_{11}$$U_2\cup U_3$$\{a\}\cup U_3$$U_2$$U_1$$\{\mathsf{box}(U_1)\}$
$\sigma_{15}$$U_2\cup U_3$$U_2$$\{a\}\cup U_3$$U_1$$\{\mathsf{box}(U_1)\}$

The claim to prove is the judgment at the root: $\langle \mathrm{id};\ \{A\}\cup R \stackrel{?}{=} \{B\}\cup\{C\};\ \varnothing\rangle \Vdash \Sigma$, where $\Sigma$ is Maude's answer set. It says that every solution is an instance of some answer.

3The ideas the tree uses

State
$\langle\alpha;E;D\rangle$: $\alpha$ maps the original variables to terms over the current variables, $E$ lists the pending equations and $D$ the recorded disequations. Its solutions are the values of the current variables that satisfy $E$ and $D$; each one gives the solution $\alpha$ of the original problem.
Judgment
$\langle\alpha;E;D\rangle\Vdash\Sigma$: every solution of the state is covered by some answer in $\Sigma$.
Alien
An element of a bag that is not a variable: $a$ inside a box, or a whole box such as $A$ in a bag of boxes. Solve treats aliens as opaque elements and counts their copies.
Count equation
For a bag equation and one element $e$, the number of copies of $e$ on each side must agree. Writing $r$ for the copies of $e$ in $R$, the root equation gives $r + [e{=}A] = [e{=}B] + [e{=}C]$, where $[e{=}A]$ is $1$ if $e$ is $A$ and $0$ otherwise.
Data $P$, $B$
For each alien $c$, the least solutions $P_c$ of its count equation; and the basis $B$, the least nonzero solutions where no alien occurs. Every solution is one particular solution plus a sum of basis vectors.
Choice, $\theta_\pi$
A choice $\pi$ picks one particular solution per alien. It determines the substitution $\theta_\pi$: each bag variable gets $\pi$'s copies of the aliens plus one fresh variable $Z_j$ per basis vector. Solve has one premise per choice.
Compatible, clique
Two aliens on the same side are compatible when nothing rules out that they are equal. A clique is a set of pairwise compatible aliens; they may all denote one element, so their count equations are added together, and side condition (S2) is checked for that sum.
(S1)–(S3)
(S1) the data really solve the count equations; (S2) every solution, for every clique, lies above some sum of picks; (S3) every nonzero solution without aliens lies above some basis vector. Together they say no solution is lost.
Cover
Closes a state with no pending equations: one answer $\sigma$ and a witness $\beta$ with $\alpha = \beta\circ\sigma$ modulo ACU.
Not in this tree Two rules do not appear here. Delete drops a trivial equation $t \stackrel{?}{=} t$. Clash closes a state whose constraints contradict each other, for example $0 \stackrel{?}{=} \mathsf{s}(N)$ for numbers (different constructors), or a disequation $t \ne t$. Both are one-step rules that need no data.

4Node by node

4.1$J_1$: the first split

At the root, the boxes $A$, $B$, $C$ are aliens of the outer bag. Whether $A$ equals $C$ depends on the values of $X$ and $Z$, and Solve needs to know this: if $A = C$, the copy of $A$ on the left cancels against $C$ on the right, which changes the count. Aliens on opposite sides that may coincide are therefore split first.

Identify $A\sim C$. Every solution has either $A = C$ or $A \ne C$. The first premise $J_2$ adds the equation $A \stackrel{?}{=} C$ to $E$; the second premise $J_6$ records $A \ne C$ in $D$.

$B$ and $C$ are on the same side. They also may coincide, but they need no split: Solve handles them as a clique (see $J_{13}$).

4.2Branch $A = C$: $J_2$ to $J_5$

$J_2$ Decomp. $\mathsf{box}$ is a free constructor, so $\mathsf{box}(\{a\}\cup X) = \mathsf{box}(Z)$ holds exactly when $\{a\}\cup X = Z$. The first equation is replaced by that one.
$J_3$ Elim $Z := \{a\}\cup X$. $Z$ does not occur in $\{a\}\cup X$, so the equation fixes $Z$. $Z$ leaves the state, and every later occurrence becomes $\{a\}\cup X$. In particular $C$ becomes $A$, so the remaining equation is $\{A\}\cup R \stackrel{?}{=} \{A\}\cup\{B\}$, and $\alpha$ now records $Z \mapsto \{a\}\cup X$.
$J_4$ Solve. The bag variable is $R$; the aliens are $A$ (once on each side) and $B$ (right). For an element $e$ with $r$ copies in $R$: $$r + [e{=}A] \;=\; [e{=}A] + [e{=}B].$$
  • $e$ is $A$ only: $r + 1 = 1$, so $r = 0$. $P_A = \{(0)\}$.
  • $e$ is $B$ only: $r = 1$. $P_B = \{(1)\}$.
  • $e$ is neither: $r = 0$. The only solution is zero, so the basis is empty and no fresh variable is created.
$A$ and $B$ are compatible: nothing in $D$ says $A \ne B$. So $\{A, B\}$ is a clique, and (S2) checks the case $e = A = B$: there $r + 1 = 2$, so $r = 1$, which lies above $p_A + p_B = (0) + (1) = (1)$. There is one choice, $\pi = (p_A, p_B)$, and $$\theta_\pi:\quad R := 0\cdot\{A\}\cup 1\cdot\{B\} = \{B\} = \{\mathsf{box}(Y\cup W)\}.$$
$J_5$ Cover by $\sigma_7$. Nothing is pending, and $\alpha$ maps $Z \mapsto \{a\}\cup X$, $R\mapsto\{\mathsf{box}(Y\cup W)\}$, and $X, Y, W$ to themselves. The witness $\beta = [U_1 := X,\ U_2 := Y,\ U_3 := W]$ turns $\sigma_7$ into exactly this $\alpha$.

4.3Branch $A \ne C$, $A = B$: $J_6$ to $J_{12}$

$J_6$ Identify $A\sim B$. $A$ (left) and $B$ (right) may also coincide, so they are split the same way: $J_7$ assumes $A = B$, and $J_{13}$ records $A \ne B$ as well.
$J_7$ Decomp. $\mathsf{box}(\{a\}\cup X) = \mathsf{box}(Y\cup W)$ becomes $\{a\}\cup X \stackrel{?}{=} Y\cup W$, an equation between bags of elements, one level down.
$J_8$ Solve, inside the boxes. The bag variables are $X, Y, W$; the only alien is the element $a$. With $(x, y, w)$ the copies of $e$ in $(X, Y, W)$: $$x + [e{=}a] \;=\; y + w.$$
  • $e = a$: $x + 1 = y + w$. Its least solutions are $(0,1,0)$ and $(0,0,1)$: the extra $a$ sits in $Y$ or in $W$. So $P_a = \{(0,1,0),\ (0,0,1)\}$, and there are two choices.
  • $e \ne a$: $x = y + w$. Its least nonzero solutions are $b_1 = (1,1,0)$ and $b_2 = (1,0,1)$. Each gets a fresh bag: $Z_1$ for elements shared by $X$ and $Y$, $Z_2$ for elements shared by $X$ and $W$.
(S3) holds because any nonzero $(x, y, w)$ with $x = y + w$ has $y \ge 1$ or $w \ge 1$, and so lies above $b_1$ or $b_2$. With a single alien, every clique is a singleton. Reading each vector as copies in $(X, Y, W)$ gives the two substitutions:
$X$$Y$$W$
$\pi_1 = (0,1,0)$$Z_1\cup Z_2$$\{a\}\cup Z_1$$Z_2$
$\pi_2 = (0,0,1)$$Z_1\cup Z_2$$Z_1$$\{a\}\cup Z_2$
Under either substitution, $A$ and $B$ both become $A' = \mathsf{box}(\{a\}\cup Z_1\cup Z_2)$. The solved equation is removed; the outer equation remains, with the substitution applied.
$J_9$ and $J_{11}$ Solve. In both premises the outer equation is now $\{A'\}\cup R \stackrel{?}{=} \{A'\}\cup\{C\}$, and $D$ contains $A' \ne C$: the disequation from $J_1$, with the substitution applied. The count equation is $r + [e{=}A'] = [e{=}A'] + [e{=}C]$, with $P_{A'} = \{(0)\}$, $P_C = \{(1)\}$ and an empty basis, exactly as at $J_4$. This time $A'$ and $C$ are not compatible, because $D$ says they differ, so no clique has two members and (S2) is checked alien by alien. One choice: $R := \{C\} = \{\mathsf{box}(Z)\}$.
$J_{10}$ Cover by $\sigma_{11}$, $J_{12}$ Cover by $\sigma_{15}$. At $J_{10}$, $\alpha$ maps $X\mapsto Z_1\cup Z_2$, $Y\mapsto\{a\}\cup Z_1$, $W\mapsto Z_2$, $R\mapsto\{\mathsf{box}(Z)\}$. The witness $\beta = [U_1 := Z,\ U_2 := Z_2,\ U_3 := Z_1]$ turns $\sigma_{11}$ into it; $X$ agrees only up to the order of $Z_1 \cup Z_2$, which is why Cover compares modulo ACU. $J_{12}$ is the same with $\pi_2$ and $\sigma_{15}$, witness $[U_1 := Z,\ U_2 := Z_1,\ U_3 := Z_2]$.

4.4Branch $A \ne C$, $A \ne B$: $J_{13}$

$J_{13}$ Solve with no choice. The equation is the original one, now with $D = \{A \ne C,\ A\ne B\}$. The aliens are $A$ (left) and $B$, $C$ (right): $$r + [e{=}A] \;=\; [e{=}B] + [e{=}C].$$
  • $e$ is $A$ only: $r + 1 = 0$ has no solution in $\mathbb N$, so $P_A = \varnothing$.
  • $e$ is $B$ only, or $C$ only: $r = 1$, so $P_B = P_C = \{(1)\}$.
$D$ makes $A$ incompatible with both $B$ and $C$. $B$ and $C$ remain compatible, so $\{B, C\}$ is a clique: (S2) checks $e = B = C$, where $r = 2$ lies above $p_B + p_C = (2)$. Because $P_A$ is empty there is no choice at all, so Solve has no premises and the branch is closed. In words: the copy of $A$ on the left must match some box on the right, and $D$ rules out both.

5Why the whole tree proves completeness

Every rule has the same shape of argument. Each solution of the conclusion is a solution of some premise, and it gives the same solution of the original problem. So a solution of the root travels upward through the tree, one rule at a time, until it reaches a leaf. Every leaf either is covered by an answer (Cover) or has no solutions (Solve with no choice). Hence every solution of the root is covered.

Here is the path of $\gamma$ from §1 ($X=\varnothing$, $Y=\{a\}$, $W=\varnothing$, $Z=\{b\}$, $R=\{\mathsf{box}(\{b\})\}$):

AtWhat $\gamma$ does
J1$A = \mathsf{box}(\{a\})$ and $C = \mathsf{box}(\{b\})$ differ, so $\gamma$ goes to $J_6$.
J6$B = \mathsf{box}(\{a\}) = A$, so $\gamma$ goes to $J_7$.
J7$\{a\}\cup\varnothing = \{a\}\cup\varnothing$ holds, so $\gamma$ stays a solution.
J8At $e = a$ the counts are $(x,y,w) = (0,1,0)$, which is $p = \pi_1$ with nothing left over, so $\gamma$ takes choice $\pi_1$ with $Z_1 = Z_2 = \varnothing$.
J9$R$ holds one copy of $C = \mathsf{box}(\{b\})$, which is $p_C$, so $R = \{C\}$.
J10Covered by $\sigma_{11}$ with $U_1 = \{b\}$, $U_2 = U_3 = \varnothing$.

The tree does not need to say in advance which path a solution takes. Each rule only guarantees that some premise receives it, and the leaves account for all premises.

6The same tree in Lean

The certificate is checked in Lean as producer/tests/pipeline/t7_example.lean. Each node is one step of the proof script:

NodesLean step
J1, J6refine identify a b ?_ ?_
J2, J7refine decomp [new equations] (by acu_decomp …), proved by the constructor's injectivity
J3refine elim f (by acu_elim …)
J4, J8, J9, J11, J13refine solve with the bag variables, the aliens, the coefficients and compatible pairs, the data $P$ and $B$, and (S0)–(S3); then acu_branches opens one goal per choice
J5, J10, J12cover with the answer and the witness

Two kinds of bookkeeping step have no node in the tree: checkpoint, which restates each state in direct form, and rename, which names Solve's fresh bags $Z_1, Z_2$.
